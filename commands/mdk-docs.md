# /mdk-docs <topic>

Looks up MDK component schemas, property documentation, and examples.

Loads `mdk-docs` skill and searches the embedded component reference for `<topic>`.
Returns the `_Type` string, all properties with types, a complete usage example, and common mistakes.

**Example topics:**
`ObjectTable` | `FormCell.ListPicker` | `ObjectHeader` | `Navigation` |
`OfflineOData` | `DataSubscriptions` | `CheckRequiredFields` | `ChangeSet`
